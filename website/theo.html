C'est le développeur en chef du projet.

C'est le membre du groupe avec la plus grande expérience, il a configuré le GitHub du projet et toutes les explications pour aider les autres membres.

Il conçoit l’architecture centrale du jeu afin de fournir une base solide pour l’ensemble des fonctionnalités. Il maîtrise le langage Python et les concepts clés du développement de jeux vidéo, tels que le réseau, la physique et l’intelligence artificielle.

Il possède également une expérience dans la création de jeux vidéo acquise lors du développement d’un jeu mobile avec Unity.
